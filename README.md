**A. JUDUL PROGRAM**

Sistem Pengelolaan Data Mahasiswa Menggunakan Binary Search Tree (BST)

**B. DESKRIPSI SINGKAT**

Program ini dibuat untuk membantu pengelolaan data mahasiswa dengan memanfaatkan struktur data Binary Search Tree (BST). Melalui program ini, pengguna dapat menambahkan data mahasiswa berupa NPM dan nama, kemudian menyimpannya secara terstruktur berdasarkan nilai NPM. Dengan penyusunan data seperti ini, proses pengelolaan menjadi lebih rapi dan mudah dipahami.

Selain itu, program juga menyediakan fitur untuk menampilkan seluruh data mahasiswa secara berurutan serta mencari data mahasiswa tertentu berdasarkan NPM yang dimasukkan. Penggunaan metode Binary Search Tree membuat proses pencarian data menjadi lebih cepat dan efisien dibandingkan pencarian biasa, sehingga program cocok digunakan sebagai contoh penerapan struktur data BST dalam bahasa pemrograman Python.
